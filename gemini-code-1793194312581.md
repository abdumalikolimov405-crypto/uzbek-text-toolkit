# Uzbek Text Toolkit 🇺🇿

Lightweight, zero-dependency Python library for Uzbek NLP preprocessing, Latin-Cyrillic transliteration, and national data validation (Phone numbers, PINFL/JSHSHIR).

## Features
- **Fast Transliteration:** Convert seamlessly between Uzbek Latin and Cyrillic scripts.
- **Data Validation:** Validate Uzbekistan phone numbers and 14-digit PINFL identifiers.
- **Zero Dependencies:** Pure Python implementation for easy integration into any microservice or AI pipeline.

## Installation
```bash
pip install uzbek-text-toolkit
